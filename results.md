# CBL VIctory results

## Gameplay · 26 November 2026

Tested on Windows with a Ryzen 9 9950X3D and GeForce RTX 5080, using the Series X profile. Build `cbaef90` presented at 3840×2160. The output size does not establish the internal resolution of individual passes.

| Area | Observation |
| --- | --- |
| Progress | The opening interior and hallways are traversable. An earlier build reached a later exterior checkpoint. |
| Picture | Walls, characters and ceiling fixtures render. During movement the player character can become nearly black or show blocky edges. In this run the user saw character detail return after standing still for about 5–10 seconds. Some later scenes have missing surfaces and clipped highlights. |
| Speed | 5.53 rendered FPS over 174 seconds facing the doorway. After movement began, the next 255 measured seconds averaged 5.25 FPS, including a lighter 30-second stretch at 6.98 FPS. These are partial-session figures. |
| Stability | An earlier control run lasted 21 min 30 s from startup to manual close, including loading. The integrated playthrough is still in progress at this measurement. |

FPS is the number of successful host-present intervals divided by their total elapsed time. For exact run commands, screenshot timings, binary identities and CPU/GPU benchmarks, see the [run notes](docs/cbl/tracker-run.md).
